Skill для Claude, который превращает агента в директолога полного цикла:
**сначала аудирует** рекламный кабинет по 65 проверкам (в первую очередь —
7 скрытых настроек, которые Яндекс включает по умолчанию и которые сливают
бюджет), затем создаёт кампании, пишет объявления, тянет лидов из Метрики и
оптимизирует ставки и бюджеты, чтобы выводить рекламу в плюс.

Работает по официальному API Яндекс.Директа v5. Только Python stdlib —
без `pip install`, без внешних зависимостей.

## Почему этот skill

Это объединение пяти ранее отдельных community-скиллов для Яндекс.Директа
в одну согласованную архитектуру. Из каждого взято лучшее:

| Преимущество | Что это даёт |
|---|---|
| Аудит по 65 проверкам (YD01-YD65) | Весовой скоринг 0-100, грейд A-F, приоритизированный план исправлений |
| Чек-лист «7 скрытых настроек» | Автопроверка самых дорогих ошибок по умолчанию: стратегия по кликам, автотаргетинг, РСЯ внутри поиска, цель «Визит» и др. |
| Юнит-экономика | Предельная ставка считается из чека, маржи и конверсии сайта, а не с потолка; проверка достаточности бюджета для обучения автостратегии |
| Blueprint-оркестратор | Вся кампания из одного JSON, идемпотентно: повторный запуск не плодит дубли |
| Rules-engine оптимизации | Пауза слива, снижение дорогих ставок, масштабирование окупаемых ключей — dry-run по умолчанию |
| Реальный ROI из CRM | Заливка офлайн-продаж в Метрику: оптимизация по выручке, а не по «заявкам» |
| A/B-тесты объявлений | Z-тест победителя, автоматическое отключение проигравших |
| Автопилот | Недельный цикл ведения одной командой + дневные алерты аномалий расхода |
| Генерация креативов | Связка с внешним API или MCP-инструментом для фото и баннеров РСЯ |
| Безопасность по умолчанию | Sandbox из коробки, cost guard на бюджеты, аудит-лог, откат `rollback.py` |
| Глубокий референс API v5 | Полная документация по каждому сервису: кампании, таргетинг, расширения, отчёты |
| Бенчмарки рынка РФ | CTR / CPC / CVR / CPA по нишам для трезвой оценки цифр |

## Быстрый старт

Установка (30 секунд): скопируй репозиторий в `.claude/skills/yandex-direct`
проекта или глобально в `~/.claude/skills/yandex-direct` — Claude увидит
skill автоматически.

Настройка (один раз, ~15 минут, полный гайд —
[`references/setup-guide.md`](references/setup-guide.md)):

1. Получи OAuth-токен Директа (права `direct:api` + `metrika:read`).
2. Заведи счётчик Метрики и цель — что считаем лидом. Не «Визит»:
   см. [`references/budget-leak-checklist.md`](references/budget-leak-checklist.md), п. 7.
3. Опционально: подготовь сервис генерации креативов (API-ключ или
   MCP-коннектор) — нужен только для генерации визуалов.

```bash
cd scripts
cp config.example.json config.json
# впиши: token, counter_id, primary_goal_id,
#        target_cpa, avg_order_value, margin, site_cvr
python direct_api.py ping     # должно вернуть: OK [SANDBOX] ...
```

По умолчанию `sandbox: true` — реальные деньги не тратятся, пока сам не
переключишь на боевой кабинет.

## Аудит: первый шаг

Первый шаг — не запуск кампании, а аудит существующего кабинета:

```bash
cd scripts
python audit.py --campaign <id> --days 30    # или без --campaign: весь аккаунт
```

Отчёт начинается с блока «7 скрытых настроек» — самых дорогих и самых
быстро чинящихся ошибок:

```
[XX] YD56  Стратегия = "Максимум кликов" вместо конверсий
[XX] YD57  Автотаргетинг на поиске без контроля
[!!] YD58  Демография "показывать всем"
[XX] YD59  РСЯ подмешана в поисковую кампанию
[XX] YD60  Устройства не ограничены при дорогом чеке / B2B
[!!] YD61  Минус-слова: только "база", без нишевых
[XX] YD62  Оптимизация по цели "Визит" вместо реального действия
[XX] YD63  Бюджет меньше, чем нужно алгоритму для обучения
```

Дальше — полный чек-лист из 65 проверок по 6 категориям с весовым
скорингом 0-100 и грейдом A-F, список Quick Wins и приоритизированный
план действий.

## Сценарии использования

Просто говори Claude по-русски:

```
"Проаудируй кабинет Директа, покажи где сливается бюджет"
"Собери кампанию под доставку цветов в Москве, бюджет 2000/день"
"Собери семантику из сидов: цветы, букеты + купить, доставка, недорого"
"Сгенерь 3 варианта объявлений для группы 222"
"Покажи слив за 2 недели и добавь минус-слова"
"Снизь CPA по кампании 111 - что предлагаешь?"
"Залей продажи из CRM, переведи на ROI-стратегию"
"Запусти автопилот по кампании 111 и дай отчёт"
```

Claude сам читает `SKILL.md`, зовёт нужные скрипты и показывает результат.
Денежные изменения — сначала dry-run, потом подтверждение. Повторные
запуски не плодят дубли (локальный `state.json`), любой залив можно
откатить (`rollback.py`).

## Скрипты

Все скрипты — в `scripts/`, у каждого есть `--help`. Записывающие действия
по умолчанию dry-run; применяются только с явным `--apply`.

| Скрипт | Назначение |
|---|---|
| `direct_api.py` | Ядро: клиент API v5, retry, разбор батч-ошибок, cost guard |
| `audit.py` | Аудит: 65 проверок, скоринг 0-100, грейд A-F |
| `build.py` | Оркестратор: вся кампания из одного blueprint, идемпотентно |
| `state.py` | Локальная карта id (без дублей) + аудит-лог `changelog.jsonl` |
| `campaigns.py` | Создание / список / пауза / бюджет / стратегия кампаний |
| `adgroups.py` | Группы, ключевые фразы, минус-слова |
| `ads.py` | Валидация лимитов + создание текстовых объявлений |
| `extensions.py` | Уточнения (callouts) |
| `keywords.py` | Ставки, аукцион, поиск сливающих и конвертящих запросов |
| `research.py` | Расширение сидов в семантику + проверка спроса |
| `adjustments.py` | Корректировки ставок: мобильные, демография |
| `negatives.py` | Общие наборы минус-слов на весь аккаунт |
| `dictionaries.py` | Справочники: регионы, валюты, константы |
| `image_ads.py` | Графические объявления РСЯ: загрузка, создание |
| `generate_creatives.py` | Генерация баннеров/фото через внешний API или MCP |
| `creative_provider.py` | Мост к провайдеру креативов (`api` / `mcp`) |
| `creative_to_image_manifest.py` | Креативы -> манифест для массовой заливки |
| `reports.py` | Статистика: кампании / группы / ключи / объявления |
| `metrica.py` | Лиды и конверсии по целям Метрики |
| `crm_upload.py` | Офлайн-конверсии из CRM -> реальный ROI |
| `optimize.py` | Rules engine: паузы, ставки, минус-слова (dry-run) |
| `abtest.py` | A/B объявлений, z-тест, отключение проигравших |
| `anomalies.py` | Алерты: скачок расхода, падение конверсий, взлёт CPA |
| `autopilot.py` | Недельный цикл ведения одной командой |
| `rollback.py` | Откат созданного за сессию (suspend, обратимо) |

## Тесты

```bash
cd scripts
python -m unittest discover -s ../tests -v
```

Оффлайн, без токена и сети — покрывают валидацию объявлений, движок
оптимизации, аудит (скоринг, грейды, проверки YD56/YD59/YD62/YD63),
идемпотентность state, cost guard и мост креативов.

## Безопасность

- Токен и `config.json` в `.gitignore` — не коммитятся.
- `sandbox: true` по умолчанию; переключение на боевой кабинет — осознанное.
- Массовые правки — только через явный `--apply` после dry-run.
- Cost guard: в проде блокируются изменения бюджета выше `kpi.max_daily_total`.
- Аудит-лог всех созданий + обратимый откат (`rollback.py` делает suspend,
  а не delete).
