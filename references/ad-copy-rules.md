# Ad Copy Rules & Generation Playbook

Как модель пишет тексты, которые **проходят модерацию** и **дают клики/лиды**.
`scripts/ads.py validate` — финальный жёсткий контроль лимитов перед заливкой.

## Лимиты символов (жёсткие, Директ режет/отклоняет)
| Элемент | Лимит | Поле API |
|---------|-------|----------|
| Заголовок 1 | **56** | `Title` |
| Заголовок 2 | **30** | `Title2` |
| Текст | **81** | `Text` |
| Отображаемая ссылка (path) | **20** | `DisplayUrlPath` |
| Быстрая ссылка — заголовок | **30** | sitelink title |
| Быстрая ссылка — описание | **60** | sitelink description |
| Уточнение (callout) | **25** | adextension |
| Быстрых ссылок | до **8** | |
| Уточнений на показ | до **4** | |

Считаем символы с пробелами. Эмодзи/спецсимволы лучше не использовать.

## Правила модерации (чтобы не словить «отклонено»)
- **Один** восклицательный знак на заголовок/текст. Без КАПСА слов целиком.
- Без «лучший/№1/самый» без подтверждённых пруфов — формулируй мягче.
- Без чужих брендов/товарных знаков, если нет прав.
- Заявления о цене/скидке должны соответствовать посадочной странице.
- Для медицины/финансов/БАД и т.п. — возможны доп. требования и дисклеймеры.
- Текст и посадочная должны совпадать по сути (релевантность).
- Контакты/телефон — через визитку/быстрые ссылки, не в тексте.

## Формула продающего объявления
`[Что] + [Выгода/УТП] + [Снятие возражения] + [CTA]`

Принципы:
1. **Заголовок 1 = ключ + конкретика.** Вставь основной запрос пользователя
   (релевантность поднимает CTR и снижает цену клика).
2. **Заголовок 2 = усилитель.** Доставка/срок/гарантия/гео.
3. **Текст = выгоды цифрами + CTA.** «Скидка 30%», «за 1 день», «от 1990 ₽».
4. **Быстрые ссылки = маршруты** в категории/действия (4–8 шт).
5. **Уточнения = доверие** без ссылок: «Гарантия 18 мес», «Рассрочка 0%».
6. Под каждую группу/интент — свой текст. На группу делай **2–3 варианта** для A/B.

## Что повышает конверсию в лид
- Гео в заголовке для локального спроса («…в Москве»).
- Цена/вилка цены отсекает нецелевых → дешевле лид.
- Срочность и дефицит — честные («осталось», «до конца недели»).
- CTA-глагол: «Закажите», «Рассчитайте», «Получите».
- Соответствие посадочной: оффер из объявления должен быть виден на странице.

## Формат для заливки (ads.py)
Модель генерит JSON-массив (см. шапку `scripts/ads.py`):
```json
[
  {
    "title": "Купить диван в Москве — каталог 2024",
    "title2": "Доставка за 1 день",
    "text": "500+ моделей в наличии. Скидки до 30%. Бесплатный замер. Закажите!",
    "href": "https://example.com/divany?utm_source=direct",
    "display_path": "divany",
    "sitelinks": [
      {"title": "Угловые диваны", "href": "https://example.com/uglovye", "description": "от 19 900 ₽"},
      {"title": "Прямые диваны",  "href": "https://example.com/pryamye"},
      {"title": "Раскладные",     "href": "https://example.com/raskladnye"},
      {"title": "Распродажа",     "href": "https://example.com/sale", "description": "скидки до 50%"}
    ],
    "callouts": ["Гарантия 18 мес", "Рассрочка 0%", "Замер бесплатно", "Доставка по РФ"]
  }
]
```

Workflow:
1. Сгенерь варианты по формуле выше.
2. `python ads.py validate --file ads.json` — почини всё, что вылезло за лимит.
3. `python ads.py create --group <id> --file ads.json`.
4. `python ads.py moderate --group <id>` — отправить на модерацию.

> UTM-метки в `href` обязательно — иначе Метрика не свяжет лид с кампанией.
> Минимум `utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}`.
