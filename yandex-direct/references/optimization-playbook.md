# Optimization Playbook — как выводить кампании в плюс

Цель: лиды по цене ≤ `target_cpa`, и при наличии чека — положительный ROI.
Движок — `scripts/optimize.py` (по умолчанию dry-run). Этот файл — логика за ним.

## Метрики
```
CTR  = clicks / impressions
CR   = conversions / clicks                 # конверсия в лид
CPC  = cost / clicks
CPA  = cost / conversions                    # цена лида  ← главный KPI
ROI  = (revenue - cost) / cost               # revenue = conversions * avg_order_value * margin
```
`avg_order_value` и `margin` берутся из `config.kpi`. Если чек неизвестен —
работаем по CPA: держим CPA ниже целевого.

## Сколько платить за лид (target_cpa)
Если знаешь экономику:
```
max_cpa = avg_order_value * margin            # верхняя граница безубыточности
target_cpa = max_cpa * (1 - желаемая_прибыль) # обычно 0.5–0.7 от max_cpa
```
Если нет — стартуй с гипотезы и снижай по факту.

## Rules engine (что делает optimize.py, по ключам)
Окно: `lookback_days` (по умолч. 14). Пороги — в `config.optimization_rules`.

| Условие | Действие |
|---------|----------|
| потрачено ≥ `min_spend_for_minus_word`, 0 конверсий | **пауза ключа** (слив) |
| кликов ≥ `min_clicks_before_pause`, 0 конверсий | **пауза ключа** |
| CPA > target × `cpa_pause_multiplier` (×1.5) | **пауза ключа** |
| CPA > target × `cpa_lower_bid_multiplier` (×1.3) | **снизить ставку** на `bid_step_pct` |
| CPA < target × `cpa_raise_bid_multiplier` (×0.7) | **поднять ставку** (масштабируем то, что окупается) |

Ставка всегда зажата в `[min_bid, max_bid]`.

Логика простыми словами: **режем слив, душим дорогое, доливаем в дешёвое и
конвертящее.** Так общий CPA ползёт вниз, а объём лидов растёт там, где выгодно.

## Минус-слова (борьба со сливом)
```
python keywords.py mine-queries --campaign <id> --days 14 --min-spend 500
```
Показывает поисковые запросы, которые жрут бюджет без конверсий. Отбери мусорные
(«бесплатно», «своими руками», «вакансии», «б/у», конкуренты) →
```
python adgroups.py minus --group <id> --words "бесплатно,своими руками,вакансии"
```
Делать **еженедельно** — это самый дешёвый способ снизить CPA.

## Ручное управление vs автостратегии
**Старт (мало данных, < ~10 конверсий/нед):** ручные ставки + rules engine.
Контролируешь каждый ключ, быстро режешь слив.

**Накопил конверсии (≥ 10/нед на кампанию):** переключай на автостратегию —
алгоритм Яндекса оптимизирует точнее на объёме:
```
python campaigns.py create --name "..." --strategy auto_cpa --goal <goal_id> --cpa 1200
# или для ROI:
python campaigns.py create --name "..." --strategy auto_roi --goal <goal_id> --roi 30
```
Автостратегии требуют рабочую цель Метрики и достаточно конверсий, иначе обучаются
плохо. Не дёргай настройки чаще раза в неделю — сбивается обучение.

## Недельный цикл ведения (что делает Claude)
1. `reports.py campaigns --days 7` + `metrica.py summary` — общая картина.
2. `keywords.py mine-queries ...` → новые минус-слова.
3. `optimize.py --campaign <id>` (dry-run) → посмотреть план → `--apply`.
4. Слабые объявления (низкий CTR) → переписать тексты, добавить варианты, A/B.
5. Масштабировать прибыльные группы: поднять бюджет/ставки на том, что в плюсе.
6. Зафиксировать изменения и метрики, сравнить с прошлой неделей.

## Чего НЕ делать
- Не паузить ключи по 2–3 кликам — нужна статзначимость (см. min_clicks).
- Не менять стратегию и ставки одновременно каждый день — нет чистоты эксперимента.
- Не лить весь бюджет в один ключ — диверсифицируй интенты.
- Не игнорировать посадочную: плохой лендинг = высокий CPA при любой оптимизации.
