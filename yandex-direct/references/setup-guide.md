# Setup Guide — Яндекс.Директ skill

Пройди один раз. ~15 минут. После этого Claude ведёт твой кабинет.

> Все шаги бесплатные. По умолчанию работаем в **песочнице** (`sandbox: true`) —
> реальные деньги не тратятся, пока ты сам не переключишь на боевой кабинет.

---

## Шаг 1. OAuth-токен для Директа

API Директа требует OAuth-токен (это не пароль от аккаунта).

1. Зайди на **https://oauth.yandex.ru/** под нужным аккаунтом → **Создать приложение**.
2. Платформа: **Веб-сервисы**. Redirect URI: `https://oauth.yandex.ru/verification_code`.
3. В правах (Доступы) добавь:
   - **Яндекс.Директ** → `direct:api` (полный доступ к API).
   - **Яндекс.Метрика** → `metrika:read` (нужно для трекинга лидов).
4. Сохрани. Скопируй **ClientID**.
5. Открой в браузере (подставь свой ClientID):
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```
6. Подтверди доступ → на странице появится **токен** (длинная строка `y0_...`).
   Скопируй его.

> Токен живёт ~1 год. Никому не показывай, в git не коммить.

### Доступ к боевому API
Песочница работает с любым токеном сразу. Для **боевого** API нужно один раз
получить доступ: в интерфейсе Директа → **Настройки** → раздел про API →
подать заявку на доступ. Обычно одобряют в течение суток.

## Шаг 2. Счётчик Метрики и цели (трекинг лидов)

Без целей Метрики оптимизация «в плюс» невозможна — нечего считать как лид.

1. **https://metrika.yandex.ru/** → создай счётчик на свой сайт (если ещё нет),
   поставь код счётчика на сайт.
2. Запиши **номер счётчика** (`counter_id`, например `87654321`).
3. Заведи **цель** = действие, которое считаем лидом:
   - Настройки счётчика → **Цели** → Добавить цель.
   - Тип: «Отправка формы» / «JavaScript-событие» / «Клик по телефону» и т.п.
   - Сохрани и запиши **ID цели** (`goal_id`).
4. Свяжи Директ и Метрику: в кампании Директа укажи этот счётчик (skill умеет
   ставить авто-стратегии по `goal_id`).

## Шаг 3. Заполни config.json

```bash
cd yandex-direct/scripts
cp config.example.json config.json
```

Открой `config.json` и заполни:

| Поле | Что вписать |
|------|-------------|
| `token` | Токен из Шага 1 (или экспортируй `YANDEX_DIRECT_TOKEN`) |
| `sandbox` | `true` для тестов, `false` для боевого кабинета |
| `metrica.counter_id` | Номер счётчика из Шага 2 |
| `metrica.primary_goal_id` | ID главной цели (лид) |
| `kpi.target_cpa` | Сколько готов платить за 1 лид (в рублях) |
| `kpi.avg_order_value` | Средний чек (для расчёта ROI) — опц. |
| `kpi.margin` | Маржа долей, напр. `0.3` = 30% — опц. |
| `kpi.site_cvr` | Конверсия сайта в продажу, в %, напр. `2` = 2% — опц., нужна для предельной ставки (`references/unit-economics.md`) |
| `audit_rules.*` | Пороги для `scripts/audit.py` (мин/макс ключей в группе, недельный бюджет ×target_cpa, порог «дорогого» чека) — см. `references/budget-leak-checklist.md` |

> Токен можно не писать в файл, а держать в переменной окружения:
> `export YANDEX_DIRECT_TOKEN=y0_xxx` — скрипты подхватят её автоматически.

`config.json` и `config.local.json` уже в `.gitignore`.

## Шаг 3.1. Подключи сервис генерации креативов

Если хочешь, чтобы skill делал не только тексты, но и **фото/баннеры для
рекламы в Яндекс.Директе**, перед первым запуском нужно дать второй доступ:

1. Выбери источник генерации:
   - **API-сервис**: внешний сервис с `api_key` / `bearer token` / `base_url`
   - **MCP-коннектор**: любой подключенный MCP/tool для генерации изображений,
     баннеров, moodboards, product shots или ad creatives
2. Подготовь и передай агенту:
   - название сервиса;
   - токен/ключ;
   - base URL или имя MCP-инструмента;
   - какие креативы нужны: фото товара, lifestyle, баннеры РСЯ, A/B-варианты;
   - формат/размеры, если они важны.
3. Агент должен **сначала запросить эти данные**, и только потом обещать
   генерацию визуалов.

### Обязательный intake для любого агента

В начале работы агент должен запросить у пользователя оба блока:

1. Доступ к Яндекс.Директу/Метрике:
   - OAuth token
   - sandbox или production
   - `counter_id`
   - `goal_id`
2. Доступ к генератору креативов:
   - API key / token или MCP connector
   - service name
   - base URL / tool name
   - типы креативов и форматы

Без этого skill должен перейти в режим уточнения, а не делать вид, что
визуальный контент уже можно собрать.

## Шаг 4. Проверка

```bash
cd yandex-direct/scripts
python direct_api.py ping
```

Ожидаемо: `OK [SANDBOX] token valid. Campaigns visible: N. Units: ...`

Если ошибка `8000` — токен неверный/протух, перевыпусти (Шаг 1).
Если `58` — нет доступа к боевому API (см. конец Шага 1), либо оставь `sandbox: true`.

Готово. Следующий шаг — не создавать кампанию, а **прогнать аудит** на
существующем аккаунте (или на песочнице), чтобы сразу поймать самые дорогие
ошибки настройки:

```bash
python audit.py --campaign <id>
```

См. `references/budget-leak-checklist.md` — 7 скрытых настроек, которые
чаще всего сливают бюджет, и как их проверяет этот скрипт. Дальше просто
говори Claude человеческим языком — см. README.
