# 🚀 Yandex.Direct Skill для Claude

Skill, который превращает Claude в твоего директолога: **сначала аудирует**
кабинет на 65 проверок (в первую очередь — 7 скрытых настроек, которые
Яндекс включает по умолчанию и которые сливают бюджет), затем создаёт
кампании, пишет объявления, тянет лидов из Метрики и **оптимизирует
ставки/бюджеты, чтобы выводить рекламу в плюс**. Может работать в связке с
внешним API или MCP-сервисом для генерации фото/баннеров под Яндекс.Директ.
Работает по официальному API Яндекс.Директа v5. Без сторонних зависимостей —
только Python (stdlib).

Это объединённая версия пяти ранее отдельных community-скиллов для
Яндекс.Директа (Python-оркестратор, bash-обёртка над API v5, аудит-скилл со
скорингом, cache-first bash-скилл, OpenClaw-скилл на memory-файлах) — код
проанализирован и переписан в один skill с единой архитектурой. Логика
аудита и оптимизации настроена по статьям из `../статьи.md` (в корне
репозитория) — они же распакованы в `references/budget-leak-checklist.md`
и `references/unit-economics.md`.

## Установка (30 секунд)

Скопируй папку `yandex-direct/` в `.claude/skills/` своего проекта (или в
`~/.claude/skills/` глобально):

```bash
cp -r yandex-direct ~/.claude/skills/
```

Claude увидит skill автоматически.

## Настройка (один раз, ~15 мин)

Полный гайд: [`references/setup-guide.md`](references/setup-guide.md). Кратко:

1. Получи **OAuth-токен** Директа (права `direct:api` + `metrika:read`).
2. Заведи **счётчик Метрики** и **цель** (что считаем лидом — не «Визит»,
   см. `references/budget-leak-checklist.md` п.7).
3. (опц.) Подготовь **сервис генерации креативов**: API-ключ/токен или
   MCP-коннектор для фото/баннеров — нужен только для генерации визуалов.
4. При первом вызове skill агент должен сначала спросить токен
   Яндекс.Директа/Метрики, `sandbox/prod`, `counter_id`, `goal_id`.
5. ```
   cd yandex-direct/scripts
   cp config.example.json config.json
   # впиши token, counter_id, primary_goal_id, target_cpa, avg_order_value, margin, site_cvr
   python direct_api.py ping     # должно вернуть OK [SANDBOX] ...
   ```

> По умолчанию `sandbox: true` — **реальные деньги не тратятся**, пока сам не
> переключишь на боевой кабинет.

## Первый шаг — аудит, не запуск

```bash
cd yandex-direct/scripts
python audit.py --campaign <id> --days 30
```

Отчёт ведёт с блока **«7 скрытых настроек»** (стратегия по кликам вместо
конверсий, неконтролируемый автотаргетинг, РСЯ, подмешанная в поиск,
устройства без ограничений, тонкий список минус-слов, цель «Визит» вместо
реального действия, недостаточный для обучения бюджет) — это самые дорогие и
самые быстро чинящиеся ошибки. Дальше — полный чек-лист из 65 проверок с
весовым скорингом 0-100 и грейдом A-F.

## Как пользоваться

Просто говори Claude по-русски:

- «Проаудируй кабинет Директа, покажи где сливается бюджет»
- «Собери кампанию в Директе под доставку цветов в Москве, бюджет 2000/день»
- «Собери семантику из сидов: цветы, букеты + купить, доставка, недорого»
- «Сгенерь 3 варианта объявлений для группы 222»
- «Покажи слив за 2 недели и добавь минус-слова»
- «Снизь CPA по кампании 111 — что предлагаешь?»
- «Залей продажи из CRM, переведи на ROI-стратегию»
- «Запусти автопилот по кампании 111 и дай отчёт»

Claude сам читает `SKILL.md`, зовёт нужные скрипты и показывает результат.
Денежные изменения — сначала dry-run, потом подтверждение. Повторные запуски
не плодят дубли (локальный `state.json`), любой залив можно откатить
(`rollback.py`).

## Что умеет (фишки)

- **Аудит по 65 проверкам** (`audit.py`) с весовым скорингом и грейдом A-F —
  включая 7 скрытых настроек по умолчанию, которые сливают бюджет.
- **Один blueprint → вся кампания** идемпотентно (`build.py`), без дублей.
- **Сбор семантики** с проверкой спроса (`research.py`).
- **Работа в паре с генератором креативов** через API или MCP для фото/баннеров.
- **Реальный ROI**: заливка продаж из CRM (`crm_upload.py`) → оптимизация по
  выручке, а не по «заявкам».
- **Автопилот** недельного цикла + дневные алерты аномалий бюджета.
- **A/B креативов** с z-тестом, авто-отключение лузеров.
- **Корректировки ставок** (моб/демография), общие минус-наборы, ставки по аукциону.
- **Юнит-экономика**: предельная ставка считается из чека, маржи и конверсии
  сайта, а не берётся с потолка (`references/unit-economics.md`).
- **Безопасность**: cost guard, аудит-лог, откат.

## Безопасность

- Токен и `config.json` — в `.gitignore`, не коммитятся.
- Боевые изменения требуют подтверждения; массовые правки — только через явный `--apply`.
- Тестируй в песочнице (`sandbox: true`), переключай на боевой осознанно.

## Пайплайн креативов

Для визуалов есть два режима:
- `creative_provider.mode = "api"`: skill реально шлёт JSON в внешний сервис
  генерации, получает картинки (`base64` или `url`) и сохраняет их локально.
- `creative_provider.mode = "mcp"`: skill генерирует `mcp_manifest.json` с
  готовыми prompt-ами и структурой запроса для любого агента/MCP-инструмента.

Базовый поток:

```bash
cd yandex-direct/scripts
python generate_creatives.py --brief brief.json
python image_ads.py upload-dir --dir generated/brief
python creative_to_image_manifest.py --input uploads.json --mode uploads \
  --href "https://example.com" --title "Заголовок" --text "Текст" > ads_manifest.json
python image_ads.py create-bulk --group 222 --manifest ads_manifest.json
```

Для `api`-режима внешний сервис должен вернуть JSON вида:

```json
{
  "assets": [
    {
      "filename": "banner1.png",
      "mime_type": "image/png",
      "base64": "<base64-bytes>"
    }
  ]
}
```

Либо вместо `base64` можно вернуть `url`.

## Тесты

```bash
cd yandex-direct/scripts
python -m unittest discover -s ../tests -v
```

Оффлайн, без токена — покрывают валидацию объявлений, движок `optimize.py`,
`audit.py` (скоринг, грейды, YD56/YD59/YD62/YD63), `state.py`, cost guard,
creative provider.
